
# ToDo管理Webアプリケーション

## 概要

PHPのWebアプリケーションフレームワーク「Laravel」を使用して開発した、タスク管理Webアプリケーションです。

ユーザーが日々のタスクを登録・編集・削除し、完了状況を管理できる仕組みを実装しました。

Webアプリケーションの仕組みを実践的に学ぶことを目的に、ログイン認証からデータベースを利用したタスク管理まで、一連の機能開発に取り組みました。

## 主な機能

- ユーザー登録・ログイン認証
- タスクの新規登録・一覧表示
- タスクの編集・削除
- タスクの完了・未完了の切り替え
- 完了状態によるタスクの表示切り替え
- ログインユーザーに紐づくタスク一覧の表示
- PostgreSQLを用いたタスク情報の保存・管理

## 使用技術

| 分類 | 技術 |
| --- | --- |
| バックエンド | PHP、Laravel 10 |
| データベース | PostgreSQL 14 |
| Webサーバー | Apache |
| 開発環境 | Docker、Docker Compose |
| データベース管理 | pgAdmin 4 |
| バージョン管理 | Git、GitHub |

## 開発で工夫したこと

### 1. タスクの状態管理

タスクごとに完了・未完了の状態を保持し、状態に応じて一覧表示を切り替える機能を実装しました。

データベースに保存された状態を更新し、画面表示にも反映させることで、タスクの進捗を管理できるようにしました。

### 2. ユーザー認証とデータ管理

Laravelの認証機能を活用し、ログインユーザーに紐づくタスクを一覧表示する仕組みを実装しました。

また、タスクの登録や編集では入力値の検証を行い、必要な情報を適切に保存できるようにしました。

### 3. Dockerによる開発環境の構築

Docker Composeを活用し、Webアプリケーションとデータベースを連携させるローカル開発環境を構築しました。

アプリケーションの実装だけでなく、サーバーやデータベースの構成についても理解を深めました。

## 開発で学んだこと

本開発を通じて、Laravelを用いたWebアプリケーション開発の基本的な流れを学びました。

特に、画面から受け取ったデータをデータベースに保存・更新し、その結果を画面に反映する一連の処理を実装することで、バックエンドとデータベースの連携について理解を深めました。

また、ルーティング、コントローラー、モデルの役割を理解し、機能ごとに処理を分けて実装する重要性を学びました。

今後は、使いやすさやセキュリティにも配慮し、より実用的なWebアプリケーションの開発に取り組みたいと考えています。
